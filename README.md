# SRS Fashion Store 🛍️

SRS Fashion Store is a simple full-stack e-commerce website for buying fashion products online.

## Features

### Customer

* Register and login
* Browse products
* Add products to cart
* Update and remove cart items
* Checkout and place orders
* View purchase history

### Admin

* Admin login
* View all customer orders
* View customer and order details

## Technologies

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* MySQL
* JWT Authentication


## Purpose

This project was created to practice full-stack web development, including frontend development, backend APIs, authentication, MySQL, and order management.
